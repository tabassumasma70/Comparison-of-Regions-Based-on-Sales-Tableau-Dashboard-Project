# Sales Analysis – Tableau Dashboard
## Project Overview and Objectives
This project presents a side-by-side regional sales analysis titled **Sales Comparisons by Region**,. The objective is to compare sales performance across two regions—**Primary Region (Central)** and **Secondary Region (East)** starting from early 2016—by evaluating key summary metrics, regional maps, and sub-category sales performance.

## Technologies and Tools Used
* **Data Visualization & BI:** Tableau Desktop / Tableau Public
* **Underlying Data & Prep:** Regional sales order dataset embedded in the workbook extract (covering order dates, regions, customers, orders, products, and sub-categories)]

## Key Features and Functionalities
* **Visualizations Built:** Side-by-side comparison views for **Central** and **East** regions featuring KPI callouts (First Order Date, Total Sales, Average Sales per Order, Number of Customers, Number of Orders, and Number of Products), regional maps, sub-category summary tables, sparkline trend lines, and horizontal bar charts across 17 sub-categories (including Chairs, Phones, Binders, Storage, Tables, Copiers, and Accessories).
* **Interactive Controls:** Structured regional comparison layout displaying total, minimum, and maximum sales alongside visual trend lines and bar indicators per sub-category.
* **Key Findings:** **East** generated higher total sales (**$678,781** vs. **$501,240** in **Central**), a higher average sales per order (**$238** vs. **$216**), more customers (**674** vs. **629**), more orders (**1,401** vs. **1,175**), and more products (**1,415** vs. **1,295**), while **Chairs** ($85,231) and **Phones** ($72,403) stood out among top sub-categories in the Central view.
